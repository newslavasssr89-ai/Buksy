# 📚 Букси

**Букси** — Android-приложение для ведения личной библиотеки и учёта чтения и прослушивания книг.

В одном приложении можно хранить бумажные, электронные и аудиокниги, отмечать прогресс, даты, оценки и статусы, организовывать библиотеку с помощью жанров, тегов и полок, а также просматривать статистику.

> Репозиторий используется для публикации официальных APK-релизов Букси и истории изменений. Исходный код приложения здесь не публикуется.

## 📱 Информация

- **Текущая версия:** 1.6.1
- **Имя пакета:** `com.buksy.app`
- **Android:** 8.0 и выше
- **minSdk:** 26
- **targetSdk:** 35
- **Язык интерфейса:** русский

## ✨ Возможности

- бумажные, электронные и аудиокниги в одной библиотеке;
- статусы и прогресс чтения/прослушивания;
- оценки по 5- или 10-балльной шкале;
- поиск книг, обложек и метаданных;
- жанры, теги и пользовательские полки;
- фильтрация, сортировка и поиск по библиотеке;
- статистика и календарь чтения;
- книжные коллажи;
- виджет текущих книг;
- импорт электронных книг и аудиофайлов;
- приём MP3, FB2 и EPUB через системное меню «Поделиться»;
- импорт из Bookmory;
- импорт статистики из Smart AudioBook Player;
- догрузка недостающих обложек и метаданных;
- резервное копирование и восстановление библиотеки;
- автоматические резервные копии;
- импорт и экспорт CSV.

## 🔄 Обновления

Каждая версия Букси публикуется отдельным GitHub Release: `v1.6.1`, `v1.6.2`, `v1.7.0` и т. д.

Для обновления скачайте APK новой версии из Releases и установите его поверх установленной Букси.

## ⚠️ Важно

Перед крупными обновлениями рекомендуется создать резервную копию библиотеки средствами приложения.

Букси предназначена для ведения собственной книжной библиотеки и статистики чтения. Приложение не является магазином книг и не распространяет платный книжный контент.

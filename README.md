# 📚 Букси

**Букси** — Android-приложение для ведения личной библиотеки и учёта чтения и прослушивания книг.

Приложение помогает собрать бумажные, электронные и аудиокниги в одной библиотеке, следить за прогрессом, сохранять оценки и даты чтения, организовывать книги по жанрам, тегам и полкам и просматривать статистику.

> Этот репозиторий используется как официальная страница распространения Букси. Здесь публикуются готовые APK и история версий. Исходный код приложения не публикуется.

## ✨ Возможности

- 📚 Учёт бумажных, электронных и аудиокниг
- 📖 Статусы и прогресс чтения и прослушивания
- ⭐ Оценки книг
- 🔎 Поиск книг, обложек и дополнительной информации
- 🏷️ Жанры, теги и пользовательские полки
- 🔍 Поиск, фильтрация и сортировка библиотеки
- 📊 Статистика чтения
- 📅 Календарь чтения
- 🖼️ Книжные коллажи
- 📱 Виджет текущих книг
- 🎧 Поддержка данных аудиокниг и чтецов
- 📂 Импорт электронных книг и аудиофайлов
- 📤 Открытие поддерживаемых файлов в Букси через системное меню «Поделиться»
- 🔄 Импорт данных из поддерживаемых книжных приложений
- 🌐 Поиск и догрузка недостающих обложек и метаданных
- 💾 Резервное копирование и восстановление библиотеки
- ⏱️ Автоматическое резервное копирование
- 📄 Импорт и экспорт данных

## 📱 Системные требования

- **Android:** 8.0 или новее
- **Минимальный API:** 26
- **Язык интерфейса:** русский
- **Имя пакета:** `com.buksy.app`

## 🔄 Обновление

Чтобы обновить Букси:

1. Скачайте APK новой версии в разделе **Releases**.
2. Установите его поверх уже установленного приложения.
3. Данные библиотеки должны сохраниться при обычном обновлении приложения.

Перед крупным обновлением рекомендуется создать резервную копию библиотеки средствами Букси.

## ℹ️ О проекте

Букси предназначена для ведения собственной книжной библиотеки и статистики чтения и прослушивания.

Приложение не является магазином книг и не распространяет платный книжный контент.

## ⚠️ Установка APK

Android может предупредить об установке приложения из стороннего источника. Для установки APK необходимо разрешить установку приложений из используемого браузера или файлового менеджера.

Скачивайте APK Букси только из раздела **Releases** этого репозитория или из других источников, официально указанных разработчиком.
